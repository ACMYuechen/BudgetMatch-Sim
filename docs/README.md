## 历史资料怎么查

[归档导航](archive/README.md)保留 Agent 阶段设计与验收、前端交付过程、权限核对快照、本地数据恢复和 VPS 切库记录。归档中的命令、账号范围和“下一步”只属于当时上下文，不能直接当作当前操作清单。

离线评测的原始报告保留在 [Agent 评测目录](../services/rpc/agent/testdata/eval/)，不为了整理文档改写历史结果。

## 文档维护约定

- **现状只维护一处**：整体完成范围放在 `status.md`；使用方法放在对应专题；README 只保留上手入口。
- **操作与记录分开**：新操作规则更新当前指南，较长的阶段日志或验收证据进入 `archive/`，并注明时间与验证范围。
- **代码与配置是事实来源**：默认值以 `.env.example`、服务 YAML 和实现为准；本机或生产的实测配置不能冒充模板默认值。
- **保留失败和限制**：不把模拟测试、本机样本或历史部署结果写成当前生产通过；安全问题与待办不能只藏在归档中。
- **不记录秘密**：密码、完整 DSN、Token、真实 `.env`、Secret 内容和私密验收材料不进入文档或 Git。
- **移动时修链接**：优先保留常用专题路径，同时更新相对路径、章节锚点和导航。
